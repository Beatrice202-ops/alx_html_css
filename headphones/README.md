# 🌐 Project: Header and Hero Section

## 🧩 Description
This project is the first step in building a fully responsive web page from a given Figma design. It focuses on creating the **Header** and **Hero Section** of the page.  
The goal is to apply strong front-end foundations such as:
- Resetting CSS styling  
- Using variables  
- Writing simple and generic CSS selectors  
- Building a clean and organized HTML structure
